## Go购 —— 全网购物比价 Agent（v2.0，主项目）

**定位**：个人自用购物比价助手（不下单版）。输入商品名 → 多平台比价 + 博主推荐 + 国补/优惠提醒 + 降价监控。目标用户：自己 → 家人同学。

**核心链路**：
```
输入商品名 → 快通道(大淘客API,秒级) + 慢通道(DrissionPage浏览器,10-30s)
→ SKU归一化匹配 → 四平台比价 → 好价卡六关 → AI导购建议(陪你出发) → 盯价推送
```

**当前状态**：v2.0 交互打磨完成，用户实测中。8/13 完成连接泄漏修复、family_pin 后端、SSE 断线检测。
