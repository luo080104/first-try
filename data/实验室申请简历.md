## 项目经历

### Go购 —— 全网购物比价 Agent（独立开发，2026 年 7-8 月）

**定位**：个人自用 AI 购物比价助手，输入商品名 → 四平台实时比价 + AI 导购建议 + 降价盯盘。

**技术栈**：Python FastAPI / SQLite / DrissionPage 浏览器自动化 / DeepSeek 大模型 API / PWA 移动端

**我做了什么**（从零到一，全部独立完成）：
- **双通道搜索架构**：联盟 API 快通道（秒级）+ 浏览器爬虫慢通道（10-30 秒全量），解决"非佣金商品搜不到"的问题
- **跨平台 SKU 归一化**：淘宝/京东/拼多多/唯品会四平台同名商品自动匹配（品牌+型号+参数）
- **AI 导购对话**：接入 DeepSeek 大模型做意图解析与推荐，带完整对话上下文
- **好价卡六关评估**：价格/店铺信誉/优惠券/运费等六维评分
- **盯价推送**：降价自动通知（Server酱 → 企业微信通道）
- 全程 230+ 次 git 提交，经历了真实项目的完整生命周期：需求 → 架构 → 开发 → 测试 → 上线 → 迭代

**难点与解决**（我认为这比功能本身更重要）：
- 浏览器爬虫被验证码/登录态问题困扰，反复调试 9 轮最终用浏览器常驻池 + headless 方案根治
- 遇到 GBK 编码、进程残留、端口锁死等系统级问题，学会从底层排查根因而不是打补丁
