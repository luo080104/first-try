# 一次破冰行动：与刘逸哲老师的一次品茶闲谈

**破冰对象**：刘逸哲，信雅达科技股份有限公司 AI 事业部负责人  
**破冰时间**：2026年8月10日  
**破冰地点**：信雅达科技股份有限公司 茶歇间  
**相处时长**：约90分钟

---

今年暑假，我在信雅达科技股份有限公司 AI 事业部实习，部门负责人是刘逸哲老师。实习的核心任务是跟随星舰项目团队从零搭建一个 AI Agent——Go购跨平台购物比价助手，基于 Python FastAPI 和 DeepSeek 大模型，实现对淘宝、京东、拼多多、唯品会四平台商品的实时搜索与智能比价。

入组之初的计划是在星舰团队学习一个月。刘老师在日常工作中对我十分关照，项目进展的每一个节点他都亲自过问。借助暑期活动的契机，也出于长久以来积累的感谢与求知的想法，我决定以品茶闲谈的形式主动约他做一次正式交流。邀约、话题设置和节奏把握全程由我主导。

谈话开始，刘老师先问了我这段时间的学习情况。我围绕三条线做了简要汇报：视频方面，跟进清华大学《跟我学 AI》系列讲座，每讲结束形成学习报告，涵盖概念梳理、算法拆解和疑问整理；阅读方面，系统学习导师推荐的 chemark《深入理解 AI Agent：设计原理与工程实践》，跟着 92 个配套实验从 ReAct 循环推到 Harness 工程，阅读进度定期向导师反馈；实践方面，从零搭建 Go购，这是投入时间最多的部分。

随后我切换到 Go购 的具体内容，从功能模块讲起，再到遇到的问题和解决过程。

Go购 从最早只能调淘宝联盟 API 返回少量佣金商品，逐步扩展为今天的状态。搜索层面，四平台并行——淘宝、京东、拼多多、唯品会——每个平台同时运行联盟 API 快通道和浏览器爬虫慢通道。前者秒级返回有佣金商品，后者兜底非佣金商品和冷门型号。两条通道互补，任一失效都不会导致搜索中断。当前系统已积累超过一万件商品，每天晚上自动运行一轮采集，三十个种子关键词配合自动扩展机制，品类覆盖率较为完整。

功能模块方面，四平台对比在同一关键词下将四个平台的价格纵向排列，组内最低价自动标注绿色，店铺评分低于 3.0 的标红警示，当前价低于市场均价七成以下的触发低价陷阱提醒。陪你出发是多轮对话导购模式，用户输入"想买个游戏本"，系统不直接塞链接，而是依次追问预算、用途、品牌偏好，在对话过程中逐步收敛范围再给出推荐。好价卡在比价完成后一键生成六关综合评估卡片——需求确认、全网比价、店铺信誉、历史价格走势、低价警示、盯价纪律——底层附加三派辩论，由性价比派、品质派和性能派各自给出独立观点。社交媒体评测参考接入了 B站、小红书和贴吧上的相关内容摘要与情感倾向，用户在对比页向下翻阅即可查看。盯价推送、购物漫游、热搜联想等模块也已补齐。

问题层面同样积累了一些经验。京东详情页从一开始就被验证码拦截，后来改用联盟 API 的 jingfen.query 榜单接口，不再触碰搜索页面。淘宝店铺页登录态一碰就清空，调试后确认是 shop{id}.taobao.com 域名的独立体系所致，与详情页 item.taobao.com 互不互通，此后店铺页被列为禁区。最棘手的是弹窗——采集引擎每次新建 Edge 浏览器进程都会在桌面弹出窗口。先后尝试了 headless 模式、窗口坐标移屏、DrissionPage 原生隐藏，都未能彻底解决。最终定位出两个根因：探活逻辑在导航期间误判浏览器死亡、以及 fill_shop 后台任务残留了双 Edge 进程。改为 CDP 原生命令探活并施加单实例保护之后，问题才算消停。刘老师听完这些问题的排查链条，对解决思路的完整度给予了肯定。他认为两周内独立推动如此多模块的迭代、且能追到根因的人，不用在星舰再待满一个月。原定四周的工程期被压缩到了三周，下一站提前定在了投研平台。

刘老师随即补充了一个具体的机会。信雅达是一家 A 股上市金融科技公司，主要服务银行与证券保险机构，近年技术主线聚焦金融大模型与场景化 Agent。近期公司与宁波银行达成了新的合作项目，涉及大量银行交易与风控数据，我进入投研平台后可以接触到这批一手数据。

话题由此切换到刘老师来信雅达之前的工作经历。他曾在阿里巴巴担任高级技术专家，职级 P8，负责多条业务线的技术团队招聘终面，三年间累计面试上千人。长期面试中他形成了一套判断逻辑：简历上的技能和项目列表只提供初始方向，真正决定评价的是候选人能否围绕一个项目讲出完整的思维链条——为什么做这个技术选型、开发中遇到什么瓶颈、解决方案是如何导出的、上线后的反思和改进在哪里。他以 Go购 举例：如果面试官问为什么选择 SQLite 而非 MySQL，能清晰说出"单机部署便捷""零运维成本""读写效率实测达标"三条理由，这段项目经历就转化成了思维资产，而不再是简历上一行干巴巴的描述。

接下来我向他分享了自己暑期自学价值投资的笔记，围绕安全边际、PE 估值和多维度财务分析等基本概念做了简要陈述。他听完后指出，自学的大方向是对的，但距离投研平台的实际工作还有两个重要区别。第一，投研分析更强调多因子交叉验证——除财务数据外，还需结合行业景气度、资金流向、舆情情绪等因素做加权判断。第二，投研成果不是单纯的买卖建议，而是一份可追溯到每一层原始数据的可复现分析报告。

关于两者的关联与差异，他认为投研分析和我在星舰阶段积累的多平台数据整合、交叉验证能力有相通之处，Agent 架构思维在投研场景中也同样适用。差别在于风险属性：工程代码出问题可以回滚修复，投资判断一旦出错直接体现为资金损失，因此投研工作在审慎性、数据完整性和结论可回溯性三个维度上的要求比软件开发更高。

整场谈话持续了约一个半小时。星舰阶段的项目积累为这次长谈提供了充足素材，刘老师以回应式提问引导对话的方式，使交流在保持信息密度的同时没有出现明显的冷场。

---

**破冰手记**

邀约之前的顾虑主要来自对自身准备度的担忧，而非对对方态度的不确。刘老师日常工作中对项目细节的反馈始终具体，他一贯认真对待交流的态度让我对这次邀约本身并不紧张。我比较担心的是第一次以非工作形式约一位经验丰富的前辈长时间聊天的准备问题——话题能不能始终连贯，节奏会不会中途断掉。

实际体验与预期有所不同。此前我对"前辈指导"的想象偏向单向传授——对方讲，我负责记。刘老师的交流风格更接近回应式对话：他会围绕我每一段表述提出追问，用追问帮我打开思路，再沿着线索往回串联。这种节奏消解了冷场的可能性，但同时也构成一种压力——回答的时候不能依赖笔记或事先准备的措辞，只能即时调用已有的理解框架。事后回想，这本身就是在检验自己到底有没有把某个问题弄透。真正想清楚的东西，才经得住连续追问。

整个破冰过程比预想中顺畅。约人之前那些关于时机是否合适、话题是否充分的心理活动，在聊了十来分钟之后就不太冒出来了。这跟技巧没有太大关系。我带去的每一块内容——项目进展、学习笔记、对投研方向的实际困惑——都是这期间实实在在做过的。坐在对方面前不必心虚，不是因为自信，是因为手上有东西。

人际交往层面的两点感受。其一，携带真实内容的邀约很少会被拒绝。大多数人在日常工作中面对的是汇报和请示，偶尔有人带着自己的思考和一杯茶坐下来，对双方而言都算是一种不错的交流方式。其二，一段对话真正的价值不取决于话术或技巧，而依赖于双方投入了多少真实的思考。
