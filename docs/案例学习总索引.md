## 三、关键设计决策（不能忘的）
1. **架构**：轻量小屋（单机 FastAPI + SQLite），不前后端分离/不上 LangGraph（WorkBuddy 确认）
2. **爬虫原则**：API 优先 + 浏览器兜底；不绕验证码；登录态方案（比指纹伪装合规）
3. **模型分工**：V4-Flash 干杂活（意图/抽取/情感），V4-Pro 干重活（AI 建议）；不装 Ollama（省钱不如 API 便宜）
4. **评估框架**：建议采纳率（曝光→点击→采纳），WorkBuddy 确认
5. **金融合规**：免责声明 + 不产可执行价位
6. **角色安装**：10 个（PM→UI/UX 设计师；嵌入式不选 IoT），待装 WorkBuddy
