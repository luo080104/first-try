1.安得烈·科斯托兰尼
投资策略及理论：在市场转折（拐点）前夕进出，逆向操作，忍受市场最后的下跌，远离市场最后的辉煌。看重的是市场趋势。
理论阐述：升跌是分不开的伙伴，如果分不清下跌的终点，就看不出上升的起点。成功的关键就是在过热阶段逆向操作。
具体做法：在下跌的过热阶段买进，即使价格继续下挫也不必害怕。在上涨的相随阶段，只观察，被动随行情波动。到了上涨的过热阶段，投资者普遍亢奋时，退出市场。

4. 边界\(B{11}\)带 + 拐点九转分析，提升抄底摸顶成功率

九转是拐点指标，而布林带是一个衡量价格波动区间的指标。将九转与布林带结合，可以同时考虑价格偏离度以及价格拐点。

买入信号：当股价触及或跌破布林带下轨（表明价格相对近期波动已严重偏低），并且同时下九转指标（拐点信号）。这两个条件同时满足，被认为是较强的技术性超跌信号，可以考虑买入博取反弹。

卖出信号：当股份触及或突破布林带上轨（表明市场相对近期波动已有大幅高），并且同时出现上九转（拐点信号））。这两个条件实时满足，被认为是较强的技术性超涨信号，可以考虑卖出或规避风险。

这种组合策略的优势在于，它要求“价格极端偏离”和“价格拐点信号”两个条件同时成立，从而提高了逆势交易（抄底摸项）的成功率。

3. 底背离与顶背离

底背离（Bullish Divergence）：当股价创出新低，但RSI指标未能同步创出新底，反而形成了一个更高的低点时，就构成了底背离。这通常暗示着虽然价格还在下跌，但下跌的动能已经在衰减，卖盘力量可能接近枯竭，趋势有潜在的反弹或反转可能，是看涨信号。

顶背离（Bearish Divergence）：当股价创新出新高，但RMI指标未能同步创新高，反而形成了一更低的高点时，就开始成了顶背离。这一通常暗示着价格还在上涨，但上涨的动能（速度和力度）已经在减弱，买盘力量可能难以为继，趋势有潜在的反转风险，是看跌信号。

4. 建议边界BoII带+动量RSI分析，提升抄底摸顶成功率

RSI是动量指标，而布林带是一个衡量价格波动区间的指标。将RSI与布林带结合，可以同时考虑市场的价格偏离度和动量状态。

买入信号：当股价触及或跌破布林带下轨（表明价格相对近期波动已严重偏低），并且同时RSI指标也进入超卖区（表明下跌动能可能衰竭）。这两个条件同时满足，被认为是较强的技术性超跌信号，可以考虑买入博取反弹。

卖出信号：当股价触及或突破布林带上轨（表明的价格相对近期波动已在近期大幅提高），并且同时RISI指标也进入到买区（表明上涨动能可能衰竭）这两个条件同时满足，被认为是较强的技性超跌后信号，可以考虑卖出或规避风险。

这种组合策略的优势在于，它要求“价格极端偏离”和“动能极端偏离”两个条件同时成立，从而提高了逆势交易（抄底摸頂）的成功率。

1. 乔治·索罗斯
投资策略及理论：在市场转折处（拐点）进出，利用羊群效应逆市主动操控市场（散步利多或利空信息，杠杆做多和做空）进行市场投机。
具体做法：在将要大起的市场中投入巨额资本引诱投资者一并狂热买进，从而进一步带动市场价格上扬，直至价格走向疯狂。在市场行将崩溃之时，率先带头抛售做空，基于市场已在顶峰，脆弱而不堪一击，任何风吹草动都可以引起恐慌性抛售（获利盘丰厚），从而又进一步加剧下跌幅度，直至崩盘。
索罗斯认为，金融市场的参与者非但是不理性的，而且在他们的决策中不可避免的引入某种偏见。当流行偏见只属于小众时，影响力尚小，但不同投资者的偏见在互动中产生群体影响力，将会演变成具主导地位的观念，就是羊群效应。
索罗斯认为，重视基本面而不重视参与者的偏见是错误的。同时，忽视基本面而只重视参与者的偏见同样是错误的。
2. 总结
索罗斯是一位基本面分析与群体偏见分析都非常优秀的投机者，且其很擅长操控市场，是一个比较嗜血的资本家。

第三、行业的集中度趋势（龙头份额）

行业集中度持续提高的行业易出长期生股（美的）。因为这样的行业有门槛，有先发优势，后浪没法让前浪死在沙滩上，易出大牛股。

相反，如果行业越来越分散，说明行业门槛不高，既有的领先者没有足够深的护城河来阻止追赶者抢夺其市场份额，这种行业一般是城头变幻大王旗，各领风骚两三年。

总结：竞争格局和集中度趋势是行业长期结构性因素，是企业间竞争力的差异。

大家都喜欢新东西，但是有没有人想过，为什么几年前声势浩大的LED、电子书、手机等新兴行业于股扶持却总是烂泥块不上墙？为什么快滑品行业（可乐、白酒）持续涌现大牛股？这是由内在的经济规律、行业格局、供需关系和商业模式决定的，不以人的意志为转移。

差异化意味着企业可以从残酷的价格竞争中挣脱出来而独立定价，从而获得超额利润，这是企业经营者梦寐以求的事情，但现实很残酷，能够真正做到差异化的企业非常稀少。

差异化经营大抵可以分为三类：

第一类是产品的差异化

第二类是服务的差异化

第三类是商业模式的差异化

(a) 差异化第一类是产品差异化

产品差异化的真正内涵是竞争对手没法轻易进行产品的复制，从而做到产品的独树一帜。

谭木匠。谭木匠的产品将简单的木梳赋予了艺术内涵和文化内涵，所以产品卖的很贵，但经营地非常好，成为木梳行业的隐形冠军。

贵州茅台。贵州茅台的历史渊源、文化诉求、产地特征等使得茅台处于高端白酒的金字塔顶端，具有非常明显的异质性和辨识性。特许经营：（a）被人们需要或渴望；（b）难以找到替代品；（c）有定价权，不受价格管控的约束。

产品差异化最普遍的方式是建立品牌，通过品牌定位实现产品差异化。

茅台的销售利润率超过50%，毛利超过90%，周转率和杠杆率都很低。高ROE主要是靠销售利润率支撑起来的。

大众品牌：薄利多销，提升知名度，强化渠道

大众品牌核心目的是通过产品的知名度来提高产品的重复购买行为，但产品并不享受明显的价格溢价。主要特征体现在三个方面：1）品牌知名度非常重要，客户每天都需要看见品牌；2）品牌的主要目的不是为了溢价销售，而是为了扩大销售数量；3）渠道和品牌同等重要，缺一不可。

伊利股份完美的契合了大众品牌的三大特征。第一，伊利每年的营销费用接近200亿元，目的就是提升知名度（客户能够天天看见它）。第二，伊利的品牌知名度非常高，销售量非常大，但并没有多少价格溢价。最后，从渠道层面来看，伊利从线上到线下，从大卖场到小的便利店，从城市到农村，伊利进行了全渠道的覆盖。

格雷厄姆的市场先生无效理论（任俊杰）

投资者可以试着将股票市场的波动当作是你身边有一位和善可亲的人，他的名字叫“市场先生”。他还是你的生意合伙人，每天从不缺席地出现在你的身边，不时会报出一个价格：要么是想买下你手中的生意权益，要么是想把自己的权益卖给你。

即使你们所共同拥有的生意具有稳定的经济特质，市场先生每天还是会固定地给出不同的报价。不无遗憾的是，这个可怜的家伙有一个毛病，那就是他的情绪很不稳定。当他高兴时，往往只会看到影响生意的那些好的因素，每当这时，他就会给出一个很高的报价，因为他害怕你会把他手中的权益买走而剥夺他即将到手的收入。当他沮丧时，在他的眼里——无论是生意还是整个世界——就会变得暗淡无光，看不到任何希望。这时他就会给出一个非常低的报价，因为他怕你会把手中的权益出售给他。

市场先生只是你的侍从，绝不是你的引路人。你要利用的是他口袋里的皮夹子，而不是他的脑瓜子。

类比：如果有一个喜怒无常的人拥有一个农场并恰好与我的农场相邻，每一天他都提出一个报价，或是想买入我们的农场，或是想卖出他自己的农场，价格则随着他的心情好坏而忽上忽下。那么我除了利用他的疯狂还能做些什么呢？如果他的报价低得可笑，而我又有些闲钱，我就会买入他的农场。如果他的报价高得离谱，我要么把自己的农场卖给他，要么不予理会继续去种自己的地就是了。
