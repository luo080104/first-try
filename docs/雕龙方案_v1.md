# 雕龙 —— 中文网文多 Agent 创作系统（方案 v1.1）

## 定位

面向中文网文作者的全流程 AI 创作副驾驶。覆盖扫榜选材→大纲设计→角色构建→并行写作→风格润色→量化质检→追踪审查→诊断分析→多平台发布。核心差异化：**学习指定作家的风格指纹，写出"像那个人"的文字。**

首版对标作家：滚开（起点，《极道天魔》《神秘之旅》《永恒剑主》）

## 各模块详细设计

### ① 市场分析师
**输入**：题材类型 + 可选平台（起点/番茄）
**过程**：
- 浏览器爬取起点/番茄榜单（复用 Go购 browser_pool）
- LLM 分析：题材热度、竞争格局、读者画像、变现潜力
- 生成 3-5 套差异化选题方案
**输出**：`选题报告.md`（金手指设计、核心卖点、爽点模式、风险评估）

### ② 架构师
**输入**：选定的选题方案
**过程**：
- 世界观构建（力量体系/地理/势力/时间线）
- **中式节拍引擎**（替代西式 beatsheet）：
  - **黄金三章**（前 6000 字）：世界观建立 + 第一次爽点 + 阶段性成果
  - **阶段突破点**（每 30-50 章）：战力升级节点，数值翻倍/新技能解锁
  - **面板更新频率**（每章或每 3 章）：系统面板格式校验
  - **卷间转折点**（每卷末）：人物关系变化/新地图开启
- 卷纲 → 章纲 → 细纲（每章 3-5 个关键情节点）
- **每章 hook_statement**（章末钩子——"本章结尾读者必须想问什么"）
- 爽点排布规划（滚开模式：3章一爽、阶段性突破、面板数值展示）
**输出**：`设定集/` + `chapter-outlines.json`（含 hook_statement 字段）
**验证门**：细纲完整性检查——总章数≥20、每章情节点≥3、hook 覆盖率 100%

### ③ 角色工坊
**输入**：架构师的世界观 + 故事大纲
**过程**：
- **15 维静态 DNA**：童年创伤/核心恐惧/内心渴望/说话习惯/身体语言/思维模式/决策方式/隐藏秘密 + MBTI/九型/大五/Socionics/霍格沃茨/道德阵营
- **3 段动态弧线**（叙事学家建议）：
  - 初始自我欺骗（"角色以为自己想要什么"）
  - 中点转折事件（"什么打破了这个错觉"）
  - 终点状态（"角色最终变成了什么样"）
- 角色关系图谱（父子/师徒/敌对/暗恋/利益）
- 每个角色的语音卡（模板句 + 禁用词 + 口头禅）
- 情绪引擎：6 种情绪 × 1-10 强度 × 章节情绪曲线
**输出**：`角色档案/` 目录

### ④ 写手池
**输入**：`chapter-outlines.json` + 角色档案 + 风格规范
**过程**：
- 子 Agent 并行：ceil(总章数 / 3) 个 Agent，每个负责 ≤ 3 章
- 写前注入上下文（追踪系统返回的上章状态 + 角色当前位置）
- 滚开风格约束（系统面板格式/战斗力数值/阶段性突破话术）
- **continuity_check**（Agent编排者 + 叙事学家建议）：每个 Agent 写完 3 章后，交叉校验相邻章的最后一段与下一章的第一段
- 写后自行进入⑤→⑥内循环
**输出**：`chapters/第N章.md`

### ⑤ 风格引擎（核心差异化）
**输入**：滚开全部作品（精校 txt/笔趣阁前 200 章）
**过程**：
1. Voiceprint + nuwa 联合提取风格指纹：
   - 功能词频率谱（的/了/是/就/却/竟）
   - 句长分布（平均句长/短句比例/超长句比例）
   - 标点指纹（逗号密度/破折号频率/感叹号节奏）
   - 战斗描写模式（招式命名规则/力量体系术语/数值展示格式）
   - 系统面板模板（滚开特有：姓名/等级/功法/技能点）
   - 爽点节奏（压制→蓄力→爆发 三段式）
   - "算账叙事"模板（见下方）
2. 生成滚开风格规范文件
3. 写手输出的每章经六层润色：
   - shuorenhua：清除 210+ AI 句式
   - humanizer-zh：8 作家声音中选"系统流/热血"模式
   - clarity-rewrite：诊断→清理→重写
   - ai-flavor-remover：结构腔/句式腔/词语腔/冗余腔
   - De-AI-Enhancer：24 项痕迹 + 段落谱系 + 标点预算
   - nuwa-skill：风格蒸馏——对齐滚开指纹
**输出**：`chapters/第N章.md`（已润色）

#### 滚开模式的"算账叙事"模板（叙事学家建议）
```
每章结构：
1. 问题引入（反派等级×人数）
2. 备战（主角获取新技能/等级提升）
3. 算账（主角战力 vs 反派战力）
4. 执行（战斗描写，占全章 ≥30%）
5. 结算（面板更新 + 新威胁预告）
```

### ⑥ 量化质检师
**输入**：润色后的章节
**过程**：
- 13 项硬性指标逐章扫描（CJK≥2000 / Dash≤20 / "不是X而是Y"≤2 / 场景轮换≥5 / 钩子不连续3章重复等）
- **三章一轮阻断 + 内循环**（Agent编排者建议）：
  - 任何一项不通过 → 退回④写手重写（最多 3 次）
  - 3 次仍不通过 → 标记"人工介入"，跳过当前章，继续下一章
- 每章必须包含系统面板或战斗力量化描述
- 主角突破必须伴随数值增长
**输出**：`质检报告.md` + `chapters/` 更新

### ⑦ 追踪审查员
**输入**：通过质检的章节
**过程**：
- O(1) 上下文注入（oh-story 追踪系统——500 章后仍 1.2KB）
- 作者/读者双时间线校验
- 因果链断裂检测 → 轻量自动修复 / 重量生成 fix-plan
- 人物 OOC 检测（对照角色档案，含 3 段动态弧线校验）
- 伏笔登记→状态跟踪→回收提醒
- **叙事承诺追踪**（叙事学家建议）：契诃夫的枪——角色说"我会回来"、"三天后决斗"等，自动登记并在到达承诺期时触发回收检查
- 显式退役：角色退场/伏笔回收必须声明
- 写前守卫：状态不一致直接阻断
**输出**：`fix-plan.json` + `审查报告.md` + `追踪/` 状态更新

### ⑧ 诊断分析师
**输入**：全本或指定章节范围
**过程**：
- 五阶段流水线（预处理→LLM标注→指标聚合→主题建模→诊断报告）
- 全本情绪曲线（每章情绪值×读者投入强度）
- 节奏曲线（快慢交替/中段塌陷检测）
- 人物关系知识图谱（ECharts/AntV G6）
- 爽点分布热力图 + 伏笔回收率统计
**输出**：`诊断报告.md` + 可视化图表包

### ⑨ 出版师
**输入**：定稿的全部章节
**过程**：
- 三级敏感词检测 + 错别字/标点/语法自动修正
- 格式标准化 + 批量替换 + 手机阅读自动分段优化
- 多平台导出：起点/番茄/晋江/纵横/17k/EPUB
**输出**：`publish/` 目录

## 爬取与风格指纹提取

### 爬取策略
- 源：笔趣阁精校版前 200 章 + 《极道天魔》《神秘之旅》《永恒剑主》
- 工具：复用 Go购 browser_pool + FictionDown 站点解析规则
- 清洗：去广告/去乱码/去重复章节/统一编码 UTF-8

### 风格指纹维度
1. 功能词频率谱 2. 句长分布 3. 标点指纹 4. 战斗描写模式
5. 系统面板模板 6. 爽点节奏 7. 禁止词汇表

### 声音保真度盲测（图书联合作者建议）
写完一卷后，取滚开原文同位置的一卷，并排对比：
- 句长分布偏差 ≤ 15%
- 战斗场景占比偏差 ≤ 10%
- 系统面板频率偏差 ≤ 20%
- "不是X而是Y"句式 = 0

## 数据流与存储

```
project/
├── 选题报告.md
├── 设定集/（世界观/力量体系/势力分布）
├── 角色档案/（{角色名}.md × 15维DNA + 3段弧线）
├── 大纲/（总纲.md + chapter-outlines.json [含 hook_statement]）
├── chapters/（第N章.md + original/ 备份）
├── 风格规范/（滚开指纹.json + 禁止词汇表.txt + 算账模板.md）
├── 追踪/（_tracking-state.json + 上下文.md + 角色状态/ + 伏笔/ + 时间线/ + 叙事承诺/）
├── 质检/ + 审查/ + 诊断/ + publish/
└── .diaolong/（系统内部状态，断点续传）
```
