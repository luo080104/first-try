# 注册操作指南（阶段 0）

> 目标：拿到大淘客 AppKey + AppSecret，用于购物助手 API 调用。
> 顺序很重要：先多多进宝 → 再大淘客。

## 第一步：注册多多进宝（5-10 分钟）

1. 打开拼多多 App → 搜索"多多进宝"（官方推广平台）
2. 用拼多多账号登录，按提示绑定个人信息
3. 完成实名认证（身份证 + 手机号）
4. 无需企业资质，个人即可

> 用途：给大淘客提供数据源授权。拼多多账号没有也能注册。

## 第二步：注册大淘客（10-15 分钟）

1. 官网注册：大淘客开放平台（WorkBuddy 搜"大淘客官网"获取准确地址）
2. 个人主体注册，无需营业执照
3. 实名认证：**身份证 + 实名支付宝 + 手机号**（三者信息必须一致！）
4. 审核周期 1-5 个工作日，通过后获得 AppKey + AppSecret

### ⚠️ 关键填写项
- **推广场景**：写"**比价工具网站**"——不要写"朋友圈推广"或留空（常见被拒原因）
- 不要用虚拟手机号
- 同一 IP 不要注册多个账号

### 审核通过后
- 在后台绑定多多进宝授权（或淘宝联盟/京东联盟任选）
- 把 AppKey + AppSecret 保存好，发给 pi 写调通脚本

## 第三步：验证（拿到 key 后，pi 来做）

- 我写一个最简 Python 脚本，调用大淘客商品搜索接口
- 确认能返回真实商品数据 → 阶段 0 完成

## 避坑清单
| 坑 | 规避 |
|----|------|
| 审核被拒（场景不明） | 推广场景写"比价工具网站" |
| 身份信息不一致 | 身份证/支付宝/手机号同一人 |
| 纯比价是否允许 | 注册时如实填写用途，个人比价工具一般无碍 |
| 个人 API 频率限制 | 搜索比价不会高频调用，够用 |
