## 一、资产配置（书 1/3 原则适配小资金）

书 1/3 原则（主业/防守/进攻）是 1000 万资金的框架——5-10 万适配版：

| 资产 | 5 万版 | 10 万版 | 说明 |
| --- | --- | --- | --- |
| **高息股底仓**（股票） | 3 万（60%） | 5.5 万（55%） | 书体系核心——水电/煤炭/银行/电信等资源垄断型 |
| **可转债**（双低+打新） | 1 万（20%） | 2.5 万（25%） | 增强仓——cb-strategy 已就位 |

| **现金**（货基/逆回购） | 0.5 万（10%） | 1 万（10%） | 常态水位——低潮时降、高潮时升（Q5） |

## 二、个股操作规则（5-8 只——Q4 定案）

### 数量与仓位（Q4 v2——集中优质——妈妈批评驱动）

```
5 万版：3-4 只 × 单只 15-20%（集中优质——每只仓位有意义）
10 万版：4-5 只 × 单只 12-15%
动态数量：低潮/高信心 → 3-4 只重仓；正常 → 5 只；高潮 → 减仓现金升
行业上限：单行业 ≤25%（书）
总仓位：个股 ≤60%（分散交给资产类别：可转债/ETF/现金——组合层面分散度不变）
单只踩雷代价（20%仓×-50%）= 组合 -10%——容忍线内——不买清单过滤雷源
```

### 选股范围（书 B2 票源）

```
优先：低成本资源垄断型（长电/神华/中海油/中煤）+ 优质银行（招行/工行）
     + 高息消费（伊利/海天——分红提升预期）
周期逆向候选（书 B6）：行业底部+估值低潮时介入（紫金/神火——大宗低潮）
每只必过：B4 价值 8 标准 + B5 估值筛选 + 不买清单（filters.py 自动跑）
```

### 买入（分批——书 B3/B2 + Q13 网格）

```
单日最多买 1 只（案例借鉴 aiagents-stock——防冲动）
分批：第一批 50% → 跌 3% 补 30% → 跌 6% 补 20%（价格网格）
时间纪律：同一只 3 周内不加第 3 批（时间网格——防接飞刀）
大盘低潮才动用"新资金"（书 B1——不抢跑）
```

### 卖出（书 S 系列 + Q7 金字塔）

```
估值溢价卖：PE 百分位 70% 以上逐步卖（书 S3）
金字塔减仓（Q7）：RSI(6)周 70 减 1/3 → 75 再减 1/3 → 80 清仓
周布林降本（书 S2）：上轨卖 1/3（口子小至少涨 20% 才卖）——留现金
杀逻辑：基本面恶化（财报/逻辑变）→ 择机卖出不再买回（书 S5）
止损双轨（Q16 雏形）：底仓=逻辑止损 / 波段仓=技术止损
```

## 三、可转债操作（增强仓——cb-strategy 已就位）

```
打新债：全打（无风险增强——Q15——小资金占比高）
双低策略：持有 2-3 只（价格低+溢价低——东财数据实时）
轮动频率：月度（每月调仓一次——低换手防摩擦）
强赎监控：触发强赎 → 提前卖出（cb_strategy 已实测）
```

## 四、现金管理（书空白——Q5 雏形）

```
常态水位：10-15%（货基/国债逆回购——年化 1.5-2%）
大盘低潮（M 系列确认）：现金降到 5%——抄底弹药（书 B1 用钱时刻）
大盘高潮（估值 80% 分位+）：现金升到 40%+（书 S4 组合同步卖）
现金=仓位的一部分——"等"是有依据的决策不是空仓焦虑
```

## 五、风控红线（书 R1-R8——filters.py 已建）

```
R1 不借钱（闲钱投资） R2 不做空 R3 不懂不做
R4 不抢跑（新钱低潮进） R5 分散（≤10%个股/≤25%行业）
R6 基本面恶化择机卖 R7 不轻易补仓（拉开差距） R8 技术降本
不买清单 N1-N14（filters.py 自动过滤——14 条全量化）
回撤熔断：组合回撤 20% → 强制减仓至 50% 以下（risk_engine 监控）
```

## 六、操作节奏（时间投入充足版——Q19 定案）

```
每日（5 分钟）：晨报（大盘状态+估值候选）——信号来了确认
每周（30 分钟）：大V 动态/持仓快检
每月（2 小时）：可转债双低轮动 + 月度复盘
每季度（半天）：持仓体检（Q14——B4/B5 重跑——逻辑变了就换）
每半年：策略/体系复盘（前向验证账本对照——Q11）
```
