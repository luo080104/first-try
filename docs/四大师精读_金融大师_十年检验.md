# 报告一：金融大师视角——《三本书》投资主张的十年检验

**2026-08-17 · 样本：25 只书中龙头池 × 2016-05~2026-08（后复权+tushare 主源）**

---

## 一、核心检验：书的第一主张"低估值买入"——十年数据不支持（表面）

把 25 只池按 **2016 年起点 PE** 分档，看十年持有年化：

| 分档 | 数量 | 平均年化 | 代表 |
| ------ | ------ | --------- | ------ |
| 起点 PE<10 | 10 只 | **3.6%** | 招行 8.0/工行 5.9/中海油 9.1/华电 -0.1/民生 -9.6 |
| 起点 PE 10-20 | 7 只 | 6.5% | 神华 12.2/太保 1.0/中石化 0.4 |
| 起点 PE>20 | 8 只 | **11.6%** | 紫金 26.5/陕煤 18.4/茅台 17.6/泸州 13.6 |

**"PE 越低越好"在 2016-2026 的 A 股龙头池被数据否定**——低 PE 组反而跑输高 PE 组 8pp。这不是书错了，是**"低估值"是必要非充分条件**。

## 二、深化：赢家输家的真正分界（书的八标准为什么不够）

| ★ 赢家（2016 起点） | 年化 | 本质 |
| ------ | ------ | ------ |
| 紫金矿业（PE 50.6） | 26.5% | **周期反转**：2016 矿产底部利润极低→PE 虚高，后来利润爆发 |
| 陕煤（PE 33.1） | 18.4% | 周期反转 + 高股息 |
| 茅台（PE 20.1） | 17.6% | **品牌垄断**（护城河第 1 位） |
| 泸州老窖（PE 23.8） | 13.6% | 品牌垄断 |
| 神华（PE 16.0） | 12.2% | 高股息资源 + 反周期（煤价下行但一体化盈利稳） |

| ✗ 输家 | 年化 | 死因 |
| ------ | ------ | ------ |
| 民生银行（PE 7.1） | -9.6% | **低 PE 价值陷阱**：PB 破净但资产质量恶化 |
| 大秦铁路（PE 8.7） | -3.3% | 低增长公用 + 煤运需求下滑 |
| 华电（PE 7.7） | -0.1% | 低增长公用 + 煤价成本挤压 |
| 宝钢（PE 31） | 0.6% | 周期没反转 + 无成长 |
| 兴业银行（PE 6.0） | 1.0% | 价值陷阱 |

**赢家 = 周期反转 + 品牌垄断 + 高股息资源**；输家 = **低 PE 价值陷阱 + 低增长公用**。

## 三、对观复打分体系的修正建议（Q11 校准点）

1. **低 PE/PB 必须叠加质量因子**——当前打分价值 40 分里 ROE/利润率/现金流已覆盖——但**应加"价值陷阱识别"**：低 PE + 资产质量恶化（拨贷比/不良率趋势/现金流衰减）→ 直接否决，而不是给估值分
2. **华电教训的直接证据**：华电十年年化 -0.1%、回撤 73%——正是书八标准全过的"低增长公用"——**观复持仓 37% 压在一只十年不涨的股票上，数据再次支持 8/30 前减仓决策**
3. **周期股 PE 失真**：紫金/陕煤证明"PE 高=贵"对周期股是反的——**行业面周期分（已 4 分）应有权重豁免**：周期底部高 PE 不扣分（利润分母失真）
4. **书"低潮入市"仍需坚持**：本检验是"任何时点买入持有"——低潮入市（大盘温度+个股低潮）是另一维度，未在此检验——维持 B3 低潮信号定案

## 四、判定

> 书的"低估值"主张：**表面证伪、实质是必要条件**——低 PE 不保证收益，但赢家清单里没有高 PB 泡沫股（茅台 PB 4.67 是品牌溢价的特殊例外）。观复 v1 打分体系的方向（多维而非单因子）被数据肯定；缺口在"价值陷阱否决层"。
