- 甲方提出"神经学习思路"（大量样本训练→最小损失函数）——认可

## 定案（方案层）

### 信号前向验证（signal_ledger）

- 每次信号触发归档（类型/参数/市场状态/时间）→ 3/6/12 月后验证命中（回撤窗口法——Q6 学的）
- 验证指标：胜率（回撤窗口）+ 平均盈亏比 + 样本量 N
- 触发校准点：a. 月度复盘 b. N≥20 样本门槛 c. 胜率跌破初始置信度-15 点立即降权
- 调整规则：新权重 = 初始×0.5 + 实测×0.5（平滑——贝叶斯简化）；参数变更需 N≥50 + 胜率差>10 点
- 降权自动+周报说明；停用/参数变更需甲方确认（半自动红线延伸）

### 参数学习化（甲方思路——四阶段生命周期）

- **所有预设参数（Q1-Q10 的）标注 "v0 先验——待训练校准"**——不是定案是种子
- 阶段一 虚拟盘期（0-6 月）：v0 先验运行——signal_ledger 采集训练数据
- 阶段二 训练期（样本达标）：网格搜索（参数候选空间+历史样本求最小损失——秒级——借思想不借 NN 复杂度）
- 阶段三 校准期：最优参数 → 样本外验证（walk-forward）→ 通过才替换（参数版本管理可回滚）
- 阶段四 循环：持续积累→再校准（在线学习）
- 损失函数：主损失 = 卡玛比率（年化/最大回撤——书低回撤理念）；辅 = 信号胜率+盈亏比
- 过拟合防护：训练样本门槛 + 样本外验证 + 正则化（平滑因子=简化版）

# Q12 定案：动态打分系统（2026-08-14 探讨——甲方认可——核心环节）

## 核心定位（甲方确认：动态打分是观复最核心的环节之一）

- strategy_score 打分系统 = 信号体系的心脏——所有标的先打分再决策
- 动态门槛 = 大盘状态连续化接入——不是拦停是提高标准

## 定案（方案层——v0 先验——全部进 Q11 参数学习化清单）

### strategy_score（0-100）

- 价值面 40（ROE10/利润率5/负债5/现金流5/股息10/成长5）
- 估值面 30（绝对10/百分位10/利率校准10——Q1 联动）
- 技术面 20（布林5/RSI背离5/九转5/量能5）
- 票源面 10（大V重仓5/龙头池5）
- 硬否决（不买清单 N + 红线 R）→ 直接 0 分（烂票永远不买——与大盘无关）

### 动态门槛（大盘状态 → 买入门槛）

- 低潮（3% 时间）→ 70 | 正常（80%）→ 80 | 高潮（17%）→ 88（收紧不停——极优仍可买）

### 设计理由（优于硬拦停）

- 书"特殊情况"例外（极度低估+大V持有可不卖）——打分天然支持
- 连续值可学习（Q11 参数学习化）——硬拦停 0/1 无法学习
- 不培养"等大盘"惰性——保留"主动找极优"动力

### 待校准（虚拟盘 6-12 月后网格搜索——卡玛比率最优）

- 三个门槛值（70/80/88）+ 四维权重（40/30/20/10）+ 各分项分数

- ✅ 方案文档更新（本节）——strategy_score 模块 = 后续搭建第一优先级（与 filters 整合）
