# Q8 定案：风格轮动（2026-08-14 探讨——方案更新）

## 数据验证

- 2008-2019：RS 高偏离后 -1.8%（均值回归）
- 2019-2026：RS 高偏离后 +3.8%（动量持续——133 次）——低偏离后 +5.1%
- 冲突原因：风格周期不同——2019 后红利=低利率+资产荒的结构性主线

## 定案（方案层）

- ❌ 放弃"简单 RS 偏离阈值轮动"（趋势期卖飞——数据否定）
- ✅ 双驱动风格管理：
  1. 底层驱动 = 利率趋势（10年国债方向——Q1 接口已有）
  2. 确认信号 = RS 12 月动量（红利/沪深300 比值动量转负 + 利率回升 → 减红利）
  3. 频率：季度（低频）
- 模块设计（后续搭建）：style_thermometer.py（利率趋势 + RS 动量 → 风格状态 + 配置建议 ±5-10%）
- 与 Q1 连接：利率校准（总量）+ 利率趋势（风格）——同一输入两种用途

- ⏳ 模块待搭建（后续——与 Q5 现金纪律模块同期）

# Q9 定案：信号失效时间窗（2026-08-14 探讨——甲方认可）

## 数据/依据

- A股大牛市周期 1.5-2.5 年（2006-07/2014-15/2019-21）——书"2.4 年"在上沿——非拍脑袋
- 当前牛市 2024-09 起 = 1.9 年（走完 80%）——剩余 ~5 个月高危窗口——"未到"概率 ~70%

## 定案（方案层）

- 书时间框架（2.4 年/2027-01）保留为**风险提醒**——不是自动卖出触发
- **牛市后期风险计分**（周度）= 时间剩余度 × 估值分位 × 技术信号
  → 到阈值（70 分）触发 Q5 现金纪律（防守联动）
- **2027-01 = 重估点**（不是判决日）——届时用估值/涨幅数据判定书框架兑现与否
- 时间 = 加重器（不是闹钟）——"未应验"的正确处理 = 给到期日 + 到期用数据说话

# Q10 定案：持有不动 + 拿住支持系统（2026-08-14 探讨——甲方认可）

## 数据/依据
- 满仓不动 6.0%/年 vs 边界触发 -2.5%/金字塔 0.5%（2002-2026 23 年）——"不动"完胜
- 2026 上半年书式执行=持有度过（躲 3 月割肉/吃 6 月顶部回吐）——最不坏路径真实成绩单
- 甲方表态：相信观复——不会随意买卖（信任基础——半自动红线不变）

## 定案（方案层）
- **拿住支持系统**（观复"拿住引擎"）：
  1. 行为诊断（behavioral_diagnosis 已建）：处置效应/过早卖出检测——周报画像
  2. 持仓季度体检（Q14 联动）：逻辑没变=系统说"拿住"；逻辑变了=该走（书 S5 边界）
  3. 噪音过滤器：波动/短期回撤 vs 逻辑变化的自动区分——信号标注"噪音(别动)" vs "逻辑变化(该走)"
- "不动"的前提 = 逻辑跟踪（边界：基本面恶化就走——不是死拿）
- 用户信任 → 信号来才动（不随意买卖）——行为诊断守护纪律
