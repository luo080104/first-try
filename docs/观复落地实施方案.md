# Q1 定案：估值利率校准（2026-08-14 探讨——甲方认可）

## 定案（方案层——按研讨原文）

- **问题**：书用十年 PE/PB 百分位定贵贱——但 2015 杠杆牛/2020 抱团把"泡沫期的贵"算进常态分母——利率环境已变（10 年国债从 3% 时代降到 1.7%）——合理估值中枢应系统性上移
- **数据验证**：沪深300 PE=14.31；10 年国债 1.6964%（5 年下行：2021 年 3.03% → 2026 年 1.70%）
- **定案**：利率校准（合理 PE = 1/(利率+股权风险溢价)）——3 年均值利率 + 情景区间（1.7%/2.2%/2.8% → 便宜 17-33%）+ 季度重估——与书的历史百分位分层使用（利率管"总量时机"——百分位管"个股筛选"）
- **结论**：当前沪深300 在全部利率情景下"便宜"（书的"63% 偏贵"在低利率时代失真）
- 落地：market_status.fair_pe_rate_calibrated ✅（已实现）
