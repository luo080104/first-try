## 多 Agent 协调（Auto-Company 借鉴，2026-08-12）

- **共识文件接力棒**：跨周期状态只存一份 consensus.md（防上下文膨胀）——与 SYNC.md 双 AI 协作流同构
- **组队规则**：每轮只挑 3-5 个最相关 agent，不全部拉上
- **收敛规则（启动流程）**：
  1. Cycle 1：Brainstorm——每个 agent 提一个想法 → 排出 top 3
  2. Cycle 2：CEO 裁决选 1 → 团队执行
  3. 卡住 → 换角度/缩范围/直接 ship（Ship > Plan > Discuss）
- **熔断**：连续 N 错 → 熔断冷却 → 限流等待（采集引擎同款）

## 记忆层 v2 设计（2026-08-12 日报精读三大项目借鉴）

> 日报里三个记忆/上下文项目精读后合并进观复记忆层设计

### 1. mem0（63k 星）——记忆算法新基准（LoCoMo 92.5/LongMemEval 94.4）

| 机制 | 借鉴 |
| --- | --- |
| **单遍 ADD-only 提取**（一次 LLM 调用，记忆只增不改） | ✅ 与棘轮哲学一致——观复记忆只增不改，防污染 |
| **实体链接**（实体抽取+嵌入+跨记忆链接） | ✅ 观复检索加实体链接（同一实体跨条目关联） |
| **多信号检索**（语义+BM25+实体并行融合） | ✅ 与 TencentDB RRF 同思路——补实体信号 |
| **时间推理**（当前状态 vs 过去事件 vs 未来计划） | ✅ 记忆加时间维度检索（"上次聊到哪"类查询） |

### 2. ECC（239k 星）——记忆信任分级

| 机制 | 借鉴 |
| --- | --- |
| **信任分级**：unreviewed 记忆不可作为指令执行；召回内容始终是不可信数据 | ✅ 观复记忆分"已验证/未验证"——未验证只能参考不能执行 |
| **跨 harness 共享记忆**（Claude/Codex/Hermes 一个库） | ✅ 小P+小布共享记忆结构化（SYNC.md 升级方向） |
| user scope 默认不启用 + MCP 身份绑定 | ✅ 防第三方污染（OpenClaw #7707 同议题） |
