## 核心决策（用户确认）

| 项 | 定案 |
| --- | --- |
| 执行模式 | **半自动**：AI 提示（带理由/依据）→ 用户确认 → 执行（不自动下单） |
| 时机策略 | **规则化**：用户/父母给规则（如月布林线下轨买入）→ 回测验证 → 策略库 → 盯盘触发 |
| 资产范围 | A股个股 + 基金（场外/ETF）+ 可转债 + 货币基金 + 国债逆回购 + 打新债 + **黄金** + **公募REITs（考虑）** |
| 排除 | 期货（用户定）+ 期权 + 北交所；港股/美股后置 |
| 资金 | <10 万（认真管理级） |
| 频率 | 每日自动检查 + 触发推送（信号频率由策略时间框架决定——月线策略月看） |
| 大V | 有清单（待提供）——参考雕龙市场分析师模式 + **看新思路**（观点聚合/可信度） |

| 使用者 | 只用户自己 |

## 需求 v1.1（2026-08-13 第二轮问答——用户确认）

| 项 | 定案 |
| --- | --- |
| 持有周期 | **混合**：主线长拿（年）+ 小仓位做时机（技术分析只用于小仓位） |
| 回撤容忍 | **虚拟盘实测**（用户提出：先跑虚拟盘测试——不亏太离谱即可——回撤底线用模拟盘验证而非空想）——**虚拟盘 = 策略上线前最后验证层**（回测=历史数据，虚拟盘=实时模拟） |
| 确认响应 | **目标 A（几分钟内）**，保底 B（几小时）——推送机制要强（即时推送+可能二次提醒） |
| 策略来源 | **A 为主**（父母有具体规则）+ **B 为辅**（经验描述→翻译成规则） |
| 收益期望 | **底线：跑赢无风险**（3-5%）；**目标：年化 >10%**（2026-08-13 用户上调——A股合理进取区间，非暴富心态；10%+ 需策略更有进取性→波动/回撤容忍度由虚拟盘实测校准） |
| 学习模式 | **A：每个提示/报告配大白话讲解**（观复兼任金融老师——越用越懂） |

## 架构新增（虚拟盘层）

```
策略 → 回测（历史验证）→ 虚拟盘（实时模拟跑 N 天）→ 验证通过 → 真钱半自动
```

- 虚拟盘数据：真实行情模拟下单（不真扣钱）——记录策略在真实市场的表现
- 与半自动一致：虚拟盘阶段 AI 提示 → 用户确认 → 模拟成交 → 记录盈亏
