（四）火电资产有大幅重估增值的基础

1. 中国火电行业盈利逻辑的根本性重构

过去盈利模式：利润≈（电价-煤价）×发电量→完全看天吃饭

未来盈利模式：综合收益=容量电价+电量电价+辅助服务收入（调峰/顶峰等）

火电从“高波动周期股”变成“类公用事业稳定资产”→估值中枢有望从8-10倍PE提升至12-15倍PE

火申未来盈利模式

1）相对同行，华电更收益于容量电价，盈利稳定性大幅提升

2）高参数、高灵活性机组更受益，辅助服务收益多

3）支撑新能源协同发展

4. 火电作为“调节器”，保障风光消纳；集团层面“风光火储一体化”项目更容易获批→火电从成本中心转向系统价值中心。

5）部分地区辅助服务补偿不足，调峰“义务化”。

6. 火申公司通过“公司+公司+公司”模式，实现“公司+股东+股东+公司+股东”的多元利益平衡。
