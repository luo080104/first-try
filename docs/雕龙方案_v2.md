# 雕龙 —— 中文网文多 Agent 创作系统（方案 v2.0）

> v2 变更：整合 9 案例深读报告（oh-story 单一权威事务 / webnovel-writer 文件即真相 / novel-writing-framework 8 铁律 / sumeru 3章并行）。方案地位：雕龙开发唯一事实源——实现与本方案冲突时，改实现或改方案，不允许"代码里悄悄多存一份"。

## 定位

面向小骆本人的中文网文 AI 创作工具。核心差异化：**学习指定作家的风格指纹，写出"像那个人"的文字**，且**写到几百章依然记得住设定、接得住伏笔、守得住大纲**。

首版对标作家：滚开（起点，《极道天魔》《神秘之旅》《永恒剑主》）
目标平台：起点 + 番茄（双平台差异内置）
成熟后：小骆自己连载赚零花钱

## 一、设计不变量（法律条款，任何实现不得违反）

1. **文件即真相**：全部状态人可读 Markdown/JSON，系统检测手改并提议结转，永不报错拒绝
2. **派生物可丢弃**：删光 .cache/ 后从源文件全量重建（CI 验收项）
3. **定稿只增不改**：已接受章节不可逆改；改设定走显式 retcon 事务
4. **事务原子性**：章提交要么完成一次 commit，要么原样保留，无中间态
5. **写评分离**：渲染与评审必须在不同上下文；机检先于模型评审
6. **升级原则**：脚本 < 模型 < 作者——能数的不让模型估，能模型判的不打扰作者
7. **不在 VCS 里再造 VCS**：版本/审计/回溯一律用 git
8. **容错读取**：解析源文件遇未知字段，保留并原样写回（不丢数据）
9. **对话即编辑器**：任何结构化修改可用一句自然语言完成
10. **成本可控**：写手用 V4-Flash，质检/润色用 V4-Pro；写手 prompt 预置质检铁律（防反复重写烧钱）

## 三、追踪系统（oh-story 单一权威事务模型）

### 核心原则
- `追踪/_tracking-state.json` = **唯一结构化权威**，不进正文 prompt
- 所有派生视图（上下文/角色快照/伏笔/作者真相/读者已知）由 `tracking_commit.py` **确定性派生**，程序**不反向解析 Markdown**
- **提交顺序**：渲染 delta → 写逐章记录 → 写派生视图 → **最后原子写 _tracking-state.json**（单提交点，失败重跑同一事务）

### tracking_commit.py 规格（借鉴 oh-story 1139 行实现）
- `atomic_write_text`：mkstemp → fsync → os.replace
- `write_if_changed`：内容相同跳过
- 容量：逐章记录 ≤1536B（硬 3072）/ 上下文卡 7 栏 ≤12KB / 快照 ≤8KB
- 输入校验：类型/字节上限/未知字段拒绝
- Windows UTF-8 输出（绕 GBK——Go购 踩坑教训）
- `check` 命令：派生视图与 state 完全一致校验

### 上下文卡 7 栏（续写注入）
当前位置 / 长期约束 / 核心角色状态 / 活跃伏笔 / 近三章速记 / 下一章承诺 / 连贯性风险

### 双时间线
作者真相 vs 读者已知（作者秘密不泄露到读者视图——信息差管理）

### 叙事承诺追踪
角色说"我会回来"→ 登记承诺文件 → 到达承诺期触发回收检查 → 回收/过期显式声明

## 四、9 模块设计（v2 修订）

### ① 市场分析师
- oh-story 扫榜 + novel-writing-framework 平台差异分析（番茄 vs 起点：爽点密度/主角形态/变现）
- 输出：选题报告.md（金手指/卖点/爽点模式/风险/平台匹配度）

### ② 架构师
- 中式节拍引擎：黄金三章（前6000字）/阶段突破点（30-50章）/面板更新频率/卷间转折
- 每章 hook_statement + 爽点排布（滚开模式：3章一爽/阶段性突破/面板数值）
- 细纲并行生成（3章/Agent + 合并一致性校验，sumeru 借鉴）
- **验证门**：章数≥20 / 每章情节点≥3 / hook 覆盖 100%

### ③ 角色工坊
- 15 维静态 DNA + 3 段动态弧线（初始自我欺骗→中点转折→终点状态）
- 语音卡（模板句/禁用词/口头禅）——novel-writing-framework 铁律6
- 角色关系图谱 + 情绪引擎（6情绪×强度×章节曲线）

### ④ 写手池
- 并行 3章/Agent（sumeru 硬约束）+ continuity_check 跨章衔接
- **写前注入**：追踪上下文卡（7栏）+ 角色档案 + 风格宪法
- **写手 prompt 预置质检铁律**（8 铁律 + 硬指标——防反复重写烧钱）
- 模型：**V4-Flash**（成本控制）
- 滚开风格约束（系统面板格式/战斗力数值/算账模板）

### ⑤ 风格引擎（核心差异化）
- 爬取：FictionDown 多站点校对（笔趣阁精校 200 章 × 3 部）——**指纹特征入库，原文不存即删**
- 指纹维度：功能词频率谱 / 句长分布 / 标点指纹 / 战斗模式 / 系统面板模板 / 爽点节奏 / 算账叙事模板
- 六层润色（shuorenhua/humanizer-zh/clarity-rewrite/ai-flavor-remover/De-AI-Enhancer/nuwa）
- **声音保真盲测**：句长偏差≤15% / 战斗占比≤10% / 面板频率≤20% / "不是X是Y"=0

### ⑥ 量化质检（novel-writing-framework 实战版）
- **8 条全局铁律**：
  1. "不是X是Y"≤2/章（正则 /不是[^—]{2,30}——是/）
  2. 元话语禁令（卷一/第X章/前文/后文/本章=0）
  3. 连续3章同场景必须切换
  4. 长线悬念间隔≥2章
  5. 感叹号+粗口初稿到位
  6. 角色语音卡说话方式不同
  7. 破折号≤20/章（脚本批量替换）
  8. **三章一轮 AI 扫描**（不攒 50 章）
- **硬指标**：CJK≥2000 | 模板段落0 | 章节差异≥1 | 重复形容词≤3 | 段落≤200字
- **AI 口水词清单**：缓缓/不由得/眼底闪过/心中升起/说不出的/这意味着/深邃/不可置信…
- **内循环**：不通过退回④重写（max 3 次）→ 仍不过标记"人工介入"
- 模型：**V4-Pro**（质量关键）

### ⑦ 追踪审查员
- 单一权威事务（见三）+ 因果链检测 + OOC 对照角色档案
- 修复分级：轻量直接改（备份 original）/ 严重自动修订大纲+重写 / 底线问题零遗漏（六类）
- 输出：fix-plan.json + 审查报告.md

### ⑧ 诊断分析师
- 全本情绪曲线 / 节奏曲线 / 人物图谱 / 爽点热力图 / 伏笔回收率
- 十维评审（novel-writing-framework）：开篇吸引/人物深度/节奏/…×10分
- 可视化：ECharts（Go购 已本地化可复用）

### ⑨ 出版师
- 敏感词三级检测 + 错别字/标点修正 + 平台格式导出（起点/番茄/EPUB）
- **平台差异**：番茄（完读率优化/前3章爆点）/ 起点（订阅导向/群像）

## 五、作者友好层（webnovel-writer 借鉴，方案 v1 缺的）

- **三段式报告**：总状态一句 + 里程碑/结论 + 下一步建议
- **错误分类**：已自动处理 / 建议确认 / 必须处理（不静默）
- **术语翻译**：工程词 → 作者能懂的写作语义
- **对话即编辑器**：改设定/弃伏笔用一句话，不学文件格式
