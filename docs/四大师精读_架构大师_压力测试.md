# 报告三：架构大师视角——《三本书》体系的稳健性压力测试

**2026-08-17 · 检验：书的投资体系在 2016-2026 三次大波动中的稳健性——25 只池十年数据**

---

## 一、十年 A 股压力环境（2016-2026 实测）

| 阶段 | 时段 | 性质 |
| ------ | ------ | ------ |
| 熔断+慢熊 | 2016-01 ~ 2018-12 | 指数从 3700→2400（-35%），个股分化 |
| 结构性牛 | 2019-01 ~ 2021-02 | 沪深300 从 2935→5807（+98%）——但 2020-07 才主升（0.5 年） |
| 长熊 | 2021-02 ~ 2024-09 | 沪深300 从 5807→3100（-47%） |
| 政策牛 | 2024-09 ~ 2026-08 | 反弹 + 分化 |

**书中体系在这四段里的表现，决定了它是不是"全天候系统"。**

## 二、压力测试 1：分散 vs 集中——尾部风险量化

25 只池十年实测（2016 起点持有）：

| 组合模式 | 平均最大回撤 | 平均年化 |
| --------- | ------------ | --------- |
| 观复式集中（5 只：华电/招行/太保/中信/平安） | **59.9%** | 3.8% |
| 书式分散（25 只等权） | **54.9%** | 6.9% |

**结论**：分散的尾部保护 = 回撤低 5pp、年化高 3.1pp——**书"单股≤10%/行业≤25%"不是教条，是数据支持的架构约束**。观复集中 5 只是规模适配（10 万资金），但代价真实存在。

## 三、压力测试 2：单点风险——最差持仓的十年

| 股票 | 十年年化 | 最大回撤 | 架构教训 |
| ------ | --------- | --------- | --------- |
| 华电（观复第一重仓 37%） | **-0.1%** | 73.3% | 单一公用股可十年不涨+回撤 73%——**37% 仓位压一只十年负收益的股票 = 架构上不可接受的单点故障** |
| 民生银行 | -9.6% | 67.3% | 低估值≠安全 |
| 大秦铁路 | -3.3% | 55.0% | 高股息≠增长 |

**架构结论**：观复当前持仓是"书的分散纪律"的反例——B 方案（8/30 前减仓至 25%）是**架构修复**，不是"割肉"。数据站在减仓这边。

## 四、压力测试 3：体系完备性——书缺什么（架构层缺口）

书体系覆盖：买入（低潮/票源）→ 持有（过程管理）→ 卖出（高位/估值）→ 风控（不买清单/分散）——**操作闭环完整**。但架构审查发现三个系统级缺口：

1. **无"规模适配层"**：书假设资金足够分散 20 只——10 万资金无法执行（每只 5000 元）——**架构需要"资金规模→组合形态"的适配规则**（观复已隐式在做，未显式定案）
2. **无"数据失效降级"**：书假设行情/财报数据永远可得——现实是接口挂/数据缺失（观复踩过 baostock 挂起）——**架构需要数据降级链**（观复已有：tushare→腾讯→成本价，但净值回退成本价=假数据——本次审计发现并已列入修复）
3. **无"规则冲突仲裁"**：低潮买入 vs 单股≤10% 冲突时听谁的？书没说——**观复已定案：数据裁决（回测+虚拟盘）**——架构上正确，需保持

## 五、架构稳健性总评

> 书的体系**操作闭环完整、参数可执行**——十年压力测试中"分散保护"和"低潮买入"被数据支持。但它是**单机系统**：没有规模适配、没有数据降级、没有冲突仲裁——观复补上了这三层（虚拟盘裁决/多源降级/定案机制），这正是观复作为"书的执行系统"存在的价值。
>
> **最刺眼的架构事实**：观复当前 89% 仓位 + 华电 37% 超限 + 净值三天扁平——三个都是"系统在跑但约束没生效"的实例。今晚的修复（集中度硬约束/净值审计/B 方案）就是架构补课。

## 六、给架构层的三条执行建议

1. **8/30 华电减仓是架构动作**（数据：十年 -0.1% + 回撤 73%）——执行时走 B 方案，不等 S 信号
2. **净值降级链修复**（tushare 收盘价优先 + 失败标记）——明天做，防止 9/12 判定用假数据
3. **"资金规模→组合形态"显式定案**：<10 万=集中 3-5 只（回撤代价 5pp 已知）、10-50 万=8-10 只、>50 万=书式分散——写入观复定案文档
