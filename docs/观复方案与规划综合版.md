## 一、项目定位（一句话）

**观复 = 投资研究/辅助 Agent**——价值投资为主线、技术分析为辅助、参考大V为助力——AI 给"策略参考"，用户策略优先执行（半自动：AI 建议 → 人确认 → 执行）。

## 二、三条红线（老师约束——不可违反）

```
① 不做实盘自动决策（半自动 = 人确认）
② AI 判断需用户可理解（讲解答疑模式——"看不懂不能信"）
③ 数据难全面/爬虫失误是真实风险（多源+兜底+漏抓检测）
```

## 四、20 问定案摘要（Q1-Q20——全部落地方案文档）

```
Q1  估值利率校准：合理PE=1/(利率+ERP)——3年均值+情景+季度重估——利率管时机/百分位管选股
Q2  RSI 趋势过滤器：背离优先于数值 + 周线 MA 趋势过滤器（数值在趋势市失效）
Q3  大V 候选+过滤：大V 信号只进候选池——必须过自己的战略层过滤才可买（不提前分级——数据驱动）
Q4  3-5 只集中（修正 v2：妈妈批评"为防守而防守"——分散交给资产类别）
Q5  现金纪律：现金=f(大盘状态)——低潮 0-20%/正常 20-40%/高潮 40%+——回撤 42.8%→26.4%（唯一全历史验证）
Q6  信号失效条件：每个信号带失效清单——九转周线 78%/月线 96%——低位 44% 失效
Q7  金字塔减仓被否定：23 年回测——满仓不动 6.0%/年 vs 金字塔 0.5%（"不动"完胜——Q10 联动）
Q8  风格轮动：利率趋势（底层）+ RS 12 月动量（确认）——季度低频——±5-10%
Q9  信号失效时间窗：2027-01 重估点（不是判决日）+ 风险计分（≥70 触发现金纪律）
Q10 拿住支持系统：逻辑没变不动——行为诊断（处置效应/过早卖出检测）
Q11 前向验证账本+参数学习化：信号→3/6/12月回填→胜率统计——N≥50+差>10点才调参（v0 先验=种子）
Q12 动态打分=核心环节：价值40/估值30/技术20/票源10——动态门槛（低潮70/正常80/高潮88）——硬否决在烂票层
Q13 抄底价格网格：跌 3/6/10% 分批加仓——两批间隔≥4周（防接飞刀）——+9.9% vs 一次性+6.6%
Q14 持仓季度体检：重打分→跌破=观察标记（不自动卖）→连续两季=换仓建议（人确认）
Q15 增强仓：打新债全打（新债日历+预计收益+确认）+ 双低可转债月频轮动（20-25%）
Q16 双轨止损：底仓 60-70%→逻辑止损（体检）；波段 30-40%→技术止损（机械）——track 字段记账
Q17 大V 可信度衰减：X 证据链（披露质量/逻辑混乱/风格漂移——不短窗口价格验证）
Q18 低潮入市左侧网格：触轨即买优于右侧确认（+6.6% vs +3.4%）——"左侧买、右侧停"
Q19 人机分工：AI 干全部执行层（数据/信号/盯盘/体检/提醒）——人时间投认知——三阶教学
Q20 产品设计反着来：AI 干 2/3/4 层——人学第 1 层——治散户倒挂病
```

## 五、需求定案摘要（六轮问答 + 乙方提问——2026-08-13/14）

```
定位：投资研究/辅助——价值投资主线/技术辅助/大V助力——用户策略优先

记账：双轨（日常告诉观复 + 月度对账单核对）——虚拟盘 10 万 + 真钱 2-3 万双轨并行
界面：手机推送为主（微信）+ 网页配置页（简单）
数据源：免费源起步（腾讯/百度/东财/akshare——七源）+ 需要时补付费
```
