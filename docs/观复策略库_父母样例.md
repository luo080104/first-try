## 一、买入规则（buy）

```yaml
# B1 低潮入市（总前提——新资金只在大盘绝对低潮入市）
name: low_tide_entry
category: buy
source: 手册47/68
core_rules:
  - 所有新资金都要大盘绝对低潮才入市（不抢跑）
  - 大盘大熊市判定（满足多数即确认低潮）：
    a. 估值底：股市综合温度 5 度以内，单项温度近 0 度
    b. 政策底：降税费（印花税）/中央汇金增持/换村长
    c. 月布林线下轨（买点，长期）
    d. 月线九转指标（买点，中期）
    e. 周布林线下轨（买点，中期）
    f. 周 RSI(6) 近 20 + 底背离（中期）
    g. 周量能明显底背离（中期）
    h. 借鉴估值和技术大V观点（六亿/小林聊股道）

# B2 票源可靠（买入范围）
name: reliable_sources
category: buy
source: 手册48-54
core_rules:
  - 只买两类票：顶级企业（一线龙头股池）+ 顶级大V重仓股
  - A股龙头池：银行(招行建行工行农行)/酒(茅台五粮液泸州老窖汾酒青岛)/保险(平安太保)/
    券商(中信东财)/能源有色(神华陕煤中煤淮北中海油紫金神火云铝)/电信(移动)/
    航运(中远海控青岛港中车)/医药(片仔癀迈瑞)/消费(伊利海天涪陵安井)/
    家电(格力美的海尔)/电力(长电川投华能水电国投国电皖能华电国际华能国际)
  - 港股龙头池：科技(腾讯阿里小米美团)/银行(招行恒生建行工行农行)/保险(平安太保财险)/
    券商(中信港交所)/电信(移动)/物业(中海保利)/航运/消费/公共(宁沪皖通粤高速B华润电力)/资源(中海油神华紫金)
  - 雪球 60+ 顶级大V：超级鹿鼎公/发财油菜君/山湖水/丹书铁券/宁静的冬日M 等（见大V清单）
  - 大V 组合：山湖水梦幻组合/发财油菜君 A股港股价值投资/APEC蓝天 三马拉车 等

# B3 技术低潮买入（趋势择时——核心买入信号）
name: technical_low_buy
category: buy
source: 主书29-36/手册55
core_rules:
  - 个股抄底 6 指标（满足越多个信号越强）：
    a. 月布林线下轨（规避倒 V 形）
    b. 月下九转
    c. 周布林线下轨（规避倒 V 形）
    d. 周 RSI(6) 到 20 以内 + 底背离
    e. 周量能底背离（极度缩量；或底部大跌但量放得很大）
    f. 顶级大V的票可放宽到周级别
  - 布林+九转组合：股价触/跌破布林下轨 + 下九转 = 较强超跌信号
  - 布林+RSI 组合：布林下轨 + RSI 超卖区（<20）= 较强超跌信号
  - 布林下轨三结构（月线）：
    a. 下轨走平（斜率 0）= 抄底成功概率最高（一次见底）
    b. 下轨下跌趋势（负斜率）= 多次踩（分批 4/8 次买）
    c. 高点跌到下轨跌幅超 -50% + 估值低 = 多数真底（仍多次踩）
  - 假底：跌幅不够大（无估值底）→ 五月内不抄底——第六个月后重新踩下轨才抄
  - 月布林开口判断：开口大（SD 大）风险大谨慎；开口小（粘合）低位=大涨节奏/高位=大跌节奏

# B4 价值选股（8 标准——3-8 项都要满足，1-2 至少满足一项）
name: value_stock_selection
category: buy
source: 主书67/手册58
core_rules:
  1. 分红率高
  2. 成长性好
  3. 有稳定盈利史，ROE 大于 10%
  4. 现金流充沛，最好经营性现金流大于利润
  5. 销售利润率大于 10%
  6. 资产负债率低，最好低于 50%，不超过 60%（电力/金融除外）
  7. 优先选择一线龙头企业
  8. 未来利润和自由现金流前景向好，分红增加（投资逻辑）
  附加：创富（股息率+增长率）和保富（利润率+ROE+现金流+负债率）双满足

# B5 估值筛选（绝对低 + 相对低 + 底线思维）
name: valuation_filter
category: buy
source: 主书67/手册60
core_rules:
  - 绝对估值低：PE < 15 或 PB < 2
  - 相对估值历史低潮（历史 10% 分位以下）
  - 最好相对国内外同行业也低估（不强求）
  - 底线思维：极端情况 PE 依旧很低 + 股息率有保障（基本面下行保护）
  - PE 好用标准：好股票当前 PE 低于其合理 PE 的一半（打五折）

# B6 高息股/周期股买入时机
name: high_dividend_buy
category: buy
source: 主书112/107
core_rules:
  - 周期股（资源垄断型）：行业周期底部、产品价格低迷、企业盈利低潮时逆向买入
    ——尽量买负债低、成本低、现金流好的龙头企业
  - 券商/基金/保险（Beta）：估值历史低位（PB 百分位）+ 月布林线踩下轨
  - 黄金估值（纽约黄金/AISC）：<1.2 严重低估 / 1.2-1.5 成本支撑区（中长期配置价值）/
    1.5-2.0 合理 / 2.0-2.5 偏高 / >2.5 高溢价
```

## 二、卖出规则（sell——第一设计项）

```yaml
# S1 技术逃顶（个股——分牛熊两种情况）
name: technical_top_sell
category: sell
source: 主书42/手册55-56
core_rules:
  - 熊市（周布林中轨下跌趋势）中期波段卖出：
    a. 周 Boll 上轨（主指标）
    b. 周上九转（辅）
    c. 周 RSI(6) 到 80（沪深300 是 70）+ 顶背离（辅）
    d. 周量能顶背离（辅）
  - 牛市（周布林中轨上升趋势）——周/月 Boll 上轨不是好卖出指标：
    a. 估值已不便宜（70 百分位之上）
    b. 月上九转
    c. 周 RSI(6) 到 80 + 顶背离
    d. 周量能顶背离（及天量天价）

# S2 周布林波段降本（大V票专用）
name: weekly_boll_reduce_cost
category: sell
source: 主书64/95/手册62
core_rules:
  - 成功票：周布林上轨卖三分之一（周布林口子小 → 至少涨 20% 才卖）——卖出部分留现金
  - 成功票大涨因业绩：建议要更多涨幅才卖三分之一降本
  - 失败票：周布林上轨全部卖（即使亏钱也卖）——卖出部分留现金
  - 失败票（基本面没变化）补仓一次（20% 仓位）——杀逻辑的失败票不补仓
  - 失败过的票：不到周布林线下轨不买回仓位
  - 成功票基本面显著改善（财报业绩大涨）：可考虑周布林中轨就买回
  - 底部起来个股涨幅一倍则退出投资

# S3 估值溢价卖
name: valuation_premium_sell
category: sell
source: 主书46/95/98
core_rules:
  - 估值 70% 分位以上逐步卖出（雪球个股历史百分位）
  - PE 百分位 66%-80% + 月上九转 → 逐步卖 50%
  - PE 百分位 >80% + 月上九转 → 全部卖
  - PE 百分位 >80% + 月上九转未出现 → 逐步卖出
  - PE 百分位 <66% → 不动
  - 股价大涨因业绩推动且估值仍便宜（中国神华H 2022）→ 估值到溢价才卖

# S4 组合同步大盘小牛卖
name: market_top_sell
category: sell
source: 手册63/主书97
core_rules:
  - 先大盘后个股：大盘小牛（月上九转+估值高）→ 个股大部分或全部卖出
  - 特殊情况：少数个股绝对低估 + 顶级大V也持有 → 可适度少量持有
  - 大盘小牛逃顶判定（7 指标）：
    a. 估值中等偏上（过去十年）→ PB 或 PE 百分位单项超 80% 逐步减仓
    b. 月上九转（技术反转核心指标）
    c. 结合徐小明/小林理论——牛市五浪才考虑卖出
    d. 股市高位周 RSI 顶背离（中期）
    e. 周量能明显顶背离（中期）
    f. 沪深300 从最低点涨到最高点涨幅超过一倍（警惕）
    g. 牛市上涨期不超过 2.4 年

# S5 止损与杀逻辑
name: stop_loss_kill_logic
category: sell
source: 主书64/95
core_rules:
  - 买完亏 10 个点以内 = 建仓成功
  - 亏 10 个点以上 或 亏损超过半年 = 失败（失败票 20% 补仓一次——基本面没变化时）
  - 长期基本面严重恶化 = 择机卖出并不再买回（杀逻辑）
  - 中短期基本面恶化（长期没问题）→ 换马同低位且中短期基本面变强的标的
  - 价值投资者止损核心 = 长期基本面的恶化（投资逻辑），不是价格止损

# S6 格雷厄姆卖出轮动
name: graham_rotation
category: sell
source: 主书94/136
core_rules:
  - 买入极低估值标的（每个不超过 2.5% 仓位）
  - 两年内涨幅超 50% 卖出；未超 50% 两年末也卖出
  - 卖出后换入新极低估值标的——找不到就留现金

# S7 巴菲特卖出三原则
name: buffett_sell
category: sell
source: 主书94
core_rules:
  - 标的价格大幅超过内在价值（贵）
  - 标的基本面出大问题（投资逻辑坏了）
  - 发现性价比更好的标的（换马）
```

## 六、估值体系（valuation）

```yaml
# V1 估值百分位法
name: valuation_percentile
category: valuation
source: 主书44
core_rules:
  - PE/PB 历史十年百分位：100% 最贵 / 75% 比较贵 / 50% 正常 / 25% 比较便宜 / 0% 最便宜
  - 用当前 PE/PB 对照历史数据库判断相对高低

# V2 六种估值方法适用
name: valuation_methods
category: valuation
source: 主书84-85
core_rules:
  - PB/PE 法：指数/行业估值首选（个股横向纵向对比）
  - PB 法适合：周期性强+重资产行业（煤炭等）
  - PE 法适合：盈利波动大的周期性企业（最好加股息率分析）
  - PS 法：初创企业（少用）
  - PEG：高速成长股（ROE<10% 不用看；辅助指标）
  - DCF：现金流折现（价值投资最重要方法——巴菲特派）

# V3 收益分解
name: return_decomposition
category: valuation
source: 主书65
core_rules:
  - 总回报 = 总股息 + 利润增长 + 估值变化（戴维斯双击→回报三击）
  - 年化回报率 = 年化股息率 + 年化利润增长率 + 年化估值变化率
  - 股息率+增长率是长期回报核心（受 ROE 影响）
```

## 八、大V 作业（bigv——超级鹿鼎公/管我财）

```yaml
# D1 超级鹿鼎公（微博+雪球——核心跟随）
name: lugong_follow
category: bigv
source: 主书58-59/102-104
core_rules:
  - 每月月末看超级鹿鼎公公布的实盘持仓（微博）
  - 通过表格看公公当下重仓股持仓比例 + 过去一个月调仓
  - 公公投资理念：追求持仓现金流——低估值+利润难下跌=宝——
    不追求最佳盈利路径追求最不坏路径（年化 10-12% 复利）——慢慢变富
  - 年化回报 = 股息率 + 年化利润增长率 + 年化估值变化率
  - 高分红股怕业绩分红下降；高成长股怕成长消失

# D2 管我财（雪球——抄作业方法）
name: guanwochai_follow
category: bigv
```
