# 全市场池十年回测报告（甲方 Q1/Q2 应询——2016-2026 全市场 2356 只）
>
> 乙方金融大师 · 2026-08-17 晚（8/19 交付提前）· 数据：tushare 全市场快照（含退市/ST 股——消除幸存者偏差）

---

## 一、样本与方法（为什么这次可信）

| 项 | 说明 |
| ---- | ------ |
| 样本 | **2016-01-08 时点全市场 5883 只 → 有效 2356 只**（2016 已上市+双日数据）——**含后来退市/ST 股**（stock_basic L/D 状态全量） |
| 收益 | 后复权（adj_factor 复权因子 × 起终价格）——含分红等效 |
| 起点 | 2016-01-08（熔断首日 1/4 后——非择时点） |
| 终点 | 2026-08-14 |
| 分组 | 全市场 PE 分档 + **行业中性化**（行业内按 PE 中位数分高低——消除行业混杂） |

**这回答了甲方的两个致命质疑**：① 不再用"书中 2025 年名单"（幸存者偏差消除）② 行业混杂用组内对比消除。

---

## 二、核心发现 1：全市场整体十年是负的（39% 胜率）

- 2356 只十年中位年化 **-1.9%**——2016 熔断高位起点，全市场平均持有十年是亏的
- 只有 **39%** 的股票十年正收益
- **含义**：书"低潮入市"（时点选择）比选股更重要——**在任何时点买入持有 ≈ 负期望，低潮入市是正期望的来源**。这从全市场角度支持了 B3/低潮信号的架构价值。

## 核心发现 2：行业中性化后——"低估值溢价"真实存在（18/19 行业）

| 统计 | 结果 |
|------|------|
| 行业内低 PE 组 vs 高 PE 组 | **19 个行业中 18 个低 PE 赢**（唯一反例：区域地产）|
| 幅度 | 多数行业差 3-5pp 年化（电气设备 +4.6pp/元器件 +6.9pp/通信 +6.7pp）|
| 结论 | **低估值溢价是真实的、跨行业的——但被行业混杂掩盖**（银行公用拖低 PE 组表现，高成长行业抬高 PE 组）|

**为什么之前 25 只池得出"PE 无效"？** 25 只里低 PE 组全是银行公用（十年跑输）、高 PE 组有紫金陕煤（周期反转赢家）——**行业效应 > 估值效应**。全市场 2356 只把行业摊平后，估值效应浮出水面。

## 核心发现 3：高股息主张——被全市场数据强力支持

| 起点股息率 | N | 中位年化 |
| ----------- | ----- | --------- |
| <2% | 1563 | **-1.7%** |
| 2-4% | 109 | +1.7% |
| 4-6% | 25 | **+6.3%** |
| >6% | 5 | +3.0%（样本少） |

**股息率 4-6% 组比 <2% 组年化高 8pp**——"高息股"是十年数据最强的单因子。这验证了小七股息率策略（66.7% 胜率）的方向，且是全市场口径。

## 三、对观复的修正（推翻/强化了什么）

| 原结论（25 只池） | 全市场修正 | 行动 |
| ------------------ | ----------- | ------ |
| "低估值无效"（PE<10 组 3.6% vs PE>20 组 11.6%） | **推翻**——行业中性化后 18/19 行业低 PE 赢 | 估值百分位/低 PE 权重**保留且应强化**——原结论是幸存者偏差+行业混杂的假象 |
| 高股息有效（小七 66.7%） | **强化**——全市场股息 4-6% 组 +6.3% 年化 | 高股息因子权重可上调（Q11 校准点） |
| （未检验）低潮入市 | **新证据**——全市场十年中位 -1.9%、胜率 39%——"任何时点买入"是负期望 | B3 低潮信号的价值被全市场数据确认——虚拟盘验证期重点观察 |
| 华电十年 -0.1% | 一致（华电在公用行业低 PE 组也平庸） | 8/30 减仓决策不受影响 |

## 四、局限（诚实标注）

1. **股息率是 2016 单点快照**——未做持有期股息再平衡（简化；股息 4-6% 组样本仅 25 只，需扩大验证）
2. **未剔除 2016 年后增发/重组股**（复权因子已含除权，但资产注入类收益可能失真）
3. **起点固定 2016-01-08**——单一时点买入（书"低潮入市"是择时买入——本检验是"任意起点持有"对照）
4. 行业分类用 stock_basic 一级行业（23 个）——比申万二级粗

---

## 五、结论

> **甲方 Q1/Q2 的质疑直接改变了项目的两个结论**：① 四大师报告的"低估值无效"是样本偏差——全市场行业中性化后低估值溢价真实存在（18/19）；② 高股息是全市场最强的单因子（+8pp）。**这正是"数据为王"的价值：第一版结论被更大样本推翻，第二版结论更接近真相。**
>
> 给 Q11 的校准建议：**估值权重维持/略升 + 高股息权重上调 + B3 低潮信号作为时点过滤器（而非选股器）**——这三条进 Q11 校准清单。
