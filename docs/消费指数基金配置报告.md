## 一、投资背景与判断

### 1.1 行业判断

消费行业处于**历史估值低位 + 基本面筑底**阶段：

- 白酒板块自 2021 年高点连续下跌 6 年（中证白酒指数累计回撤约 50%+）
- 2026 年出现阶段性"反攻"迹象（2025 年 3 月单日暴涨 5%、2026 年机构观点转多：中信/国海等认为行业底部已现）
- 消费复苏逻辑：居民收入预期修复 → 消费意愿回升 → 食品饮料/家电龙头业绩弹性

### 1.2 投资性质

- 长期配置型（3 年以上持有周期）——消费行业周期底部适合左侧分批布局
- 被动指数化投资（不选个股，避免个股风险）
- 定投+低位加仓策略（平滑择时风险）

### 2.2 选指数逻辑（三步）

```
第一步：明确"消费"定义
  → 教科书级"主要消费"= 食品饮料+农牧（中证主要消费）
  → 若想含家电/汽车可选消费 → 消费50/消费龙头

第二步：看集中度风险
  → 主要消费：前三大权重（茅台+伊利+五粮液）≈37%——集中度高但质量高
  → 消费龙头：分散度更好

第三步：看当前周期
  → 白酒占比较高的指数（主要消费/白酒）弹性大——适合底部左侧
  → 均衡型（消费龙头/消费50）波动小——适合稳健持有
```

**结论：主选「中证主要消费」（纯度+弹性），配「消费龙头」（均衡+质量）**

```

剩余 2 份：右侧确认（指数站上 60 日均线）后加
```

### 5.3 定期动作

| 频率 | 动作 |
| --- | --- |

### 5.4 退出/止损规则

- **基本面恶化**（非价格）：白酒批价持续下行、消费数据连续 3 个月走弱 → 减仓至 50%
- **估值修复**：主要消费指数 PE 回到历史 60% 分位以上 → 开始分批止盈
- **止损线**：组合浮亏 25% → 暂停定投（不断补），等基本面信号

## 六、风险提示（重要）

1. **白酒 6 年下跌周期**：底部"可能"到了但未确认——左侧布局有继续下跌风险
2. **权重集中**：茅台一家占主要消费指数 16%——单票风险显著
3. **指数基金不保本**：净值随市场波动
4. **择时错误风险**：若消费复苏不及预期（经济弱复苏），可能长期磨底
5. **费率虽低但不是零**：0.50% 管理费长期复利影响（持有 10 年约 5% 成本）
